# Convertisseur d’unités

Application web avec un backend Express et un frontend React/Material UI. Elle convertit les pieds et mètres, ainsi que les litres et gallons US.

## Démarrage

Ouvrez deux terminaux depuis la racine du projet.

```powershell
cd backend
npm start
```

```powershell
cd frontend
npm run dev
```

Ouvrez ensuite http://localhost:5173. L’API écoute sur http://localhost:3001.

## Vérifications

```powershell
cd backend
npm test
```

```powershell
cd frontend
npm run build
```
